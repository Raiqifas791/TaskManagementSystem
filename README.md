# Task Management System

A web-based project and task management application built with Laravel and Blade. The application helps users organize personal tasks, manage multiple projects, invite team members, and collaborate on shared work.

## Features

- User registration and authentication
- Create and manage multiple projects
- Personal task management
- Invite team members through email
- Accept or reject project invitations
- Manage project membership
- Create and assign project tasks
- Track task status and priority
- Secure access to projects and tasks

## Technology Stack

- **Backend:** Laravel, PHP
- **Frontend:** Blade, HTML, CSS
- **Database:** MySQL
- **Version Control:** Git and GitHub
- **Documentation:** Markdown

## Project Structure

The project will follow Laravel's standard directory structure.

- `app/` — Application logic, models, and controllers
- `database/` — Migrations, factories, and seeders
- `resources/views/` — Blade templates
- `routes/` — Application routes
- `public/` — Public assets and resources

*Note: The application code will be added during the development phase.*

## Project Workflow

1. Users register and log in.
2. Users create and manage projects.
3. Project owners invite registered users by email.
4. Invited users accept or reject invitations.
5. Accepted members collaborate on project tasks.
6. Users manage task assignments, priorities, and status.

## Security

The application will implement authentication, server-side authorization, input validation, and database integrity checks to protect project and task information.
